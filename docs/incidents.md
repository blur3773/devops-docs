# Журнал типовых инцидентов
| Инцидент | Признак | Диагностика |
|---|---|---|
| Неиспользуемая переменная | Красный Pylint | Static analysis |
| Недостаточные права | Deploy не получает OIDC-токен | deploy-pages и permissions |
| Битая ссылка | Ошибка strict build | Build documentation |
| Старая версия | Прежняя страница после deploy | URL, SHA и кэш |

## Правило разбора
Симптом, компонент, доказательство, причина, исправление, проверка восстановления.
