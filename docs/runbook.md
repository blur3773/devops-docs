# Эксплуатация
## Штатная публикация
1. Убедитесь, что проверка `pylint` в Pull Request успешна.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation.
4. Дождитесь успеха заданий `build` и `deploy`.
5. Откройте URL окружения `github-pages` и проверьте главную страницу.

## Ручной перезапуск
Actions → Publish documentation → Run workflow.

## Диагностика
Определите отказавший этап: CI, сборка сайта, загрузка артефакта или публикация.
Читайте журнал конкретного шага и установите причину перед повторным запуском.
